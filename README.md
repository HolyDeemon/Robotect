# Robotect

Для запуска нужен установленный Docker Desktop и Git.

Сначала склонируйте репозиторий.

```bash
git clone https://github.com/HolyDeemon/Robotect.git
cd Robotect
```

Дальше все команды выполняются в этой папке, там лежит `docker-compose.yml`.

## Запуск

```bash
docker compose up --build
```

Первый запуск скачивает образы и собирает сайт. Это может занять несколько минут. Дождитесь, пока в логе появятся контейнеры `postgres`, `db`, `login`, `math` и `web` без сообщений об ошибке. Повторяющиеся строки `GET /case?case_id=1` с ответом `200 OK` — это проверка, что база жива. Их можно не останавливать.

Когда контейнеры поднялись, откройте в браузере http://localhost:8080.

Готового аккаунта нет. Нажмите регистрацию и создайте своего пользователя: имя и фамилия, email и пароль от 5 символов. После входа откроются каталог, подбор решения и симуляция.

В базе уже есть кейс, модель робота и коэффициенты. Свои параметры объекта задаются на сайте. Кнопка «Подобрать решения» сохраняет их и считает экономику. В личный кабинет можно перейти по email в шапке сайта. Вкладка симуляции в проекте становится активной после того, как экономика посчиталась.

Пока эта команда работает в окне, сайт доступен. `Ctrl+C` в этом окне останавливает контейнеры. Если нужно освободить терминал и оставить сайт запущенным, используйте фоновый режим:

```bash
docker compose up --build -d
```

Флаг `-d` уводит контейнеры в фон. Состояние смотрите командой `docker compose ps`. Логи одного сервиса: `docker compose logs -f web`.

## Если порт 8080 занят

Сайт публикуется только на порту 8080. Если по этому адресу открывается другая программа, в `docker-compose.yml` у сервиса `web` замените левое число в строке `"8080:80"` на свободный порт, например `"8090:80"`. Правое число не меняйте. Затем выполните:

```bash
docker compose up -d
```

Сайт откроется на новом порту, например http://localhost:8090.

## Остановка

Если контейнеры запущены в текущем окне, нажмите `Ctrl+C`, затем:

```bash
docker compose down
```

Если они были запущены с `-d`, достаточно второй команды. Регистрации и данные базы сохраняются в томе `pgdata` и переживут следующий `docker compose up`.

Чтобы удалить и этот том вместе с регистрациями:

```bash
docker compose down -v
```
