# Robotect

## Запуск

Нужны Docker и Docker Compose.

```bash
docker compose up --build
```

Первый запуск скачивает образы и собирает сайт, это занимает несколько минут. Когда контейнеры поднимутся, откройте http://localhost:8080 и зарегистрируйтесь. Готового аккаунта нет.

Кейс, робот и коэффициенты уже лежат в базе. После входа можно подбирать решение, смотреть экономику и запускать симуляцию.

## Если порт занят

В `docker-compose.yml` у сервиса `web` замените левое число в `"8080:80"` на свободный порт и снова выполните `docker compose up -d`. Сайт откроется на этом порту.

## Остановка

```bash
docker compose down
```

Регистрации сохраняются. Чтобы удалить и их, выполните `docker compose down -v`.
